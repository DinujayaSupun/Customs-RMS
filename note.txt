Customs RMS Quick Notes
=======================

Run backend (from rms-backend):
mvn spring-boot:run
or
mvnw spring-boot:run

Run frontend (from rms-frontend):
npm run dev

Run backend + frontend together (from repo root):
npm install
npm run dev:all
dev:all uses backend Maven Wrapper (`rms-backend\\mvnw.cmd`) so global Maven is not required.
dev:all sets MAVEN_USER_HOME to repo-local `.m2` for stable wrapper behavior.
dev:all prints URLs at startup:
- Frontend: http://localhost:5173
- Backend : http://localhost:8080

Run backend tests:
mvn test

Run frontend E2E smoke:
npm run test:e2e

Important:
- Spring Security is enabled and required.
- Auth model is JWT-based.
- Use README.md as the primary setup and workflow reference.
- If logs scroll too fast, increase terminal scrollback/history size.
- Hibernate SQL query spam is disabled by default for cleaner backend logs.
